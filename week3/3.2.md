# 3.2 structure of C program

## Components

    - Headers (extra info functionalities of program )
    - function definitions
    - comments and Documentation
    - Statements and expressions
    - variables
    - style and indentation (to make it understandable and readable)

## Example C program
```c
#include <stdio.h>  // Header file inclusion
# define N 10      // Macro definition

int addNums(int* a,int numvals){
    int i;
    int sum;
    sum=0;
    for (i=0;i<numvals;i++){
        sum=sum + a[i];
    }
    return sum;
}

/**
 * the top level function that is automatically called when program starts executing
 */ 

int main(void){
    int a[N]={3,2,5,7,1,4,2,3,6,9}; // variable declaration and initialization
    printf("Sum = %d\n", addNums(a,N));

    return 0;
}
```

## Explanation of the example program
- `#include <stdio.h>`: This line includes the standard input-output library, which provides functionalities for input and output operations. It gives us the `printf` function.
- `#define N 10`: This line defines a macro named `N` with a value of `10`, which is used to specify the size of the array.
    - Something with #define is called a preprocessor directive.
    - it is not a variable, but a symbolic name for a constant value.
    - we cannot change its value during program execution.
- `int addNums(int* a, int numvals)`: This is a function definition for `addNums`, which takes an array of integers and the number of values as parameters and returns
    the sum of the integers in the array.
- int i; int sum;: These lines declare two integer variables, `i` and `sum`, used for iteration and storing the sum, respectively.
- `for (i=0; i<numvals; i++)`: This is a for loop that iterates through the array elements to calculate the sum.
- `int main(void)`: This is the main function where the program execution starts.
- `int a[N] = {3,2,5,7,1,4,2,3,6,9};`: This line declares and initializes an array `a` of size `N` with ten integer values.


- Syntax is the first step checked by the compiler.
- Semantics is the meaning of the code.
- Comments: 
    - Single line comments start with `//`
    - Multi-line comments are enclosed between `/*` and `*/`
    - Documentation comments are enclosed between `/**` and `*/`
